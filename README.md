# Portals Flipper на GitHub Actions

Бот присылает в Telegram выгодные лоты с Portals. Сам он ничего не покупает. Работает на серверах GitHub, VPS не нужен.

## Как бот оценивает лот
Для каждого нового лота в пределах вашего баланса бот собирает:
- **Текущие лоты** той же модели и отдельно той же модели с тем же фоном.
- **Реальные продажи** за последние 30 дней: медиану по модели и по модели с фоном.

Оценка рынка — **меньшее** из «минимальной цены выставленного лота» и «медианы продаж». Оценка консервативная, чтобы не переплатить. Уведомление приходит, если:
- скидка от оценки не меньше `/discount` (по умолчанию 15%);
- чистая прибыль после **комиссии покупателя и продавца** не меньше `/profit`.

Бот также показывает редкость модели, фона и символа, отмечает красивый номер (до 100 или 1000, одинаковые цифры, зеркальный, круглый, «лесенка») и монохром (модель и фон одного цвета). Номер и монохром в оценку не заложены: это возможный бонус сверху.

## Шаг 1. Подготовьте данные
1. Создайте бота у **@BotFather** и сохраните его токен.
2. Узнайте свой ID у **@userinfobot**.
3. Зайдите на **my.telegram.org** → *API development tools*, создайте приложение и сохраните `api_id` и `api_hash`.

## Шаг 2. Получите TG_SESSION (один раз)
Это ключ, через который бот входит в Portals от вашего имени.

**С телефона через Google Colab:** откройте colab.research.google.com, создайте блокнот и выполните две ячейки:

Введите номер телефона и код из Telegram. Строка сессии придёт вам в «Избранное».

**С компьютера:** `pip install kurigram tgcrypto && python login.py`.

> ⚠️ TG_SESSION даёт полный доступ к вашему аккаунту. Храните её только в GitHub Secrets. Отозвать её можно в Telegram: *Настройки → Устройства*.

## Шаг 3. Создайте репозиторий на GitHub
1. Создайте **публичный** репозиторий: для публичных Actions бесплатны без лимита минут. В приватном бесплатных 2000 минут в месяц, а боту на круглосуточную работу нужно около 43 000.
2. Загрузите файлы: `bot.py`, `login.py`, `requirements.txt`, `.gitignore` и `.github/workflows/flipper.yml`. Путь к последнему важен, файл должен лежать именно в этой папке.
3. Код в публичном репозитории видят все, но секреты и состояние скрыты.

## Шаг 4. Добавьте секреты
*Settings → Secrets and variables → Actions → New repository secret*:

| Secret | Значение |
|---|---|
| `BOT_TOKEN` | токен от @BotFather |
| `OWNER_ID` | ваш Telegram ID |
| `API_ID` | с my.telegram.org |
| `API_HASH` | с my.telegram.org |
| `TG_SESSION` | строка из шага 2 |

На вкладке **Variables** можно задать необязательные настройки: `BUYER_FEE` и `SELLER_FEE` (по умолчанию `0.05`, то есть 5%), `BALANCE`, `DISCOUNT`, `MIN_PROFIT`, `POLL_SECONDS`.
**Сверьте комиссии с тем, что сейчас показывает Portals при покупке и продаже**, и при необходимости поправьте их.

## Шаг 5. Запустите
*Actions* → **Portals Flipper** → **Run workflow**. Бот напишет вам в Telegram. Отправьте ему число: это ваш баланс в TON.

Дальше бот работает сменами почти по 6 часов. Следующая смена стоит в очереди и стартует сразу после предыдущей. Настройки и уже просмотренные лоты сохраняются между сменами. Команды, отправленные в паузе между сменами, бот выполнит, как только запустится.

## Команды
- Число, например `50` — баланс в TON.
- `/discount 15` — минимальная скидка от оценки рынка, %.
- `/profit 0.5` — минимальная чистая прибыль, TON.
- `/scan` — проверить последние ~100 лотов.
- `/pause`, `/resume`, `/status`.

## Ограничения
- Между сменами бывает пауза в несколько минут, а расписание GitHub иногда запаздывает.
- Правила GitHub не рассчитаны на круглосуточных ботов в Actions. Есть риск, что GitHub отключит Actions в репозитории.
- API Portals неофициальный: если Portals его поменяет, бот перестанет работать до исправления.
